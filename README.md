# 🎟️ VibeTix | Discover and Book Tickets

**VibeTix** is a sleek, modern ticketing platform designed for the South African market. It allows users to discover and browse featured events, from music concerts and sports matches to lifestyle experiences, all in one place.

## 🌐 Live Demo
👉 **[View the Live VibeTix Website](https://kgosana950.github.io/VibeTix-/)**

## ✨ Features

*   **Featured Events:** A dedicated section showcasing premium events like "Escape to Sun City" and "Loftus Season Tickets".
*   **Music Events:** A curated list of upcoming concerts and festivals (e.g., "Winky D: Tete-A-Tete", "Faithful With Bucie").
*   **Dynamic Event Cards:** Each event card displays:
    *   A high-quality image.
    *   The event title and location.
    *   The date and time.
    *   **Exact price ranges** (e.g., "Weekdays(R305-R415) - Weekend(R370-R470)").
*   **Mega Dropdown Menus:** Interactive navigation with dropdowns for "Events" and "Categories" (Music, Lifestyle, Sport, Comedy, etc.).
*   **Responsive Design:** Fully fluid layout that adapts to mobile, tablet, and desktop screens.

## 🛠️ Tech Stack

*   **HTML5:** Semantic structure.
*   **CSS3:** Custom properties (variables), Flexbox, CSS Grid, and hover transitions.
*   **Vanilla JavaScript (ES6+):** Dynamically rendering the event grid from a simulated database.
*   **Font Awesome:** For icons (search, heart, calendar, map-marker).
*   **Google Fonts:** `Inter` typeface for a clean, modern look.
